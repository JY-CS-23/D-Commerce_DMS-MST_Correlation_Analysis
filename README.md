# 디지털 광고 매출액과 모바일 쇼핑 거래액 분석 앱

2026 데이터분석 연구발표회를 위한 Streamlit 대시보드입니다. KOSIS의 PC·모바일 디지털 광고비와 모바일 쇼핑 거래액을 연도별로 정리하고, 추이·상관관계·상품군별 성장률·변동성을 탐색합니다.

## 폴더 구성

```text
project/
├── app.py
├── requirements.txt
├── README.md
└── data/
    ├── PC_세부광고유형별_광고비_데이터분석연구발표회.xlsx
    ├── 모바일_세부광고유형별_광고비_데이터분석연구발표회.xlsx
    └── 온라인쇼핑몰_판매매체별_상품군별거래액_데이터분석연구발표회.xlsx
```

엑셀 파일은 `data` 폴더 또는 `app.py`와 같은 폴더에 둡니다. 파일명에 `PC`와 `광고비`, `모바일`과 `광고비`, `거래액`이 들어 있으면 자동으로 탐색합니다.

## 실행 방법

Python 3.10 이상을 권장합니다.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

라이브러리 설치 및 실행:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 주요 기능

1. 연도별 광고비와 모바일 쇼핑 거래액 꺾은선그래프
2. 연도 범위, 광고 매체(PC/모바일/합계/각각), 상품군 다중 선택
3. 금액·전년 대비 증가율·지수 보기 및 추정치 포함 여부 선택
4. 광고비 합계의 선형 추세선, 연간 증가액의 최소·최대·평균 및 증가액 추세선 기울기
5. 광고비 합계와 모바일 쇼핑 거래액의 산점도, 피어슨 상관계수 및 추세선
6. 상품군별 연평균 복합성장률(CAGR) 막대그래프와 표
7. 표준편차·범위·최솟값·최댓값 및 전년 대비 증가율의 최솟값·최댓값
8. 분석에 사용된 값 표와 CSV 다운로드

## 계산 기준과 주의사항

- 광고비는 원본 표의 `총계-총계-소계` 행만 사용합니다. 세부 행은 총계를 분할한 값이므로 합산하면 중복될 수 있습니다.
- PC와 모바일 광고비 합계는 두 매체에 모두 값이 있는 연도만 계산합니다.
- 쇼핑 거래액은 `상품군별(2)=소계`, `판매매체별(1)=모바일쇼핑` 행만 사용하고 월별 금액을 연도별로 합산합니다.
- 월별 자료가 12개월 모두 존재하지 않는 연도는 연간 합계 비교에서 제외합니다.
- 원자료 단위인 백만 원을 조 원으로 환산합니다(백만 원 ÷ 1,000,000).
- 열 이름에 `e)`가 붙은 광고비는 추정치, 월 열에 `p)` 등이 붙은 자료는 잠정치로 표시합니다.
- CAGR은 지정한 시작·종료 연도의 거래액으로 계산합니다. 두 연도 값이 모두 있고, 시작·종료 거래액이 양수이며, 기간이 1년 이상이어야 계산됩니다.
- 표준편차는 선택한 기간의 값이 평균 주변에서 얼마나 흩어져 있는지를 요약합니다. 최솟값·최댓값은 해당 선택 기간 안의 극값입니다.
- 분석 연도 수가 적고 두 지표 모두 장기 상승 추세일 수 있으므로, 상관계수만으로 인과관계를 주장하지 않습니다. 광고비 통계는 쇼핑 관련 광고만을 별도로 집계한 값이 아닙니다.
- 금액 그래프에서 광고비와 쇼핑 거래액은 서로 다른 축에 표시됩니다. 선의 높이를 직접 비교하지 말고 변화 양상을 확인하세요.
